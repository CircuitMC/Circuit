# Vanilla compatibility ledger

Generated by `tools/compat_ledger.py` from the files in [`compatibility/`](../compatibility/); do not edit. The ledger records, for each target version, which vanilla features Circuit implements and what evidence supports each claim. Its families and milestones are those of the [vanilla completion roadmap](VANILLA_COMPLETION.md).

**Implementation states:** `implemented` (complete for the feature as described), `partial` (some behavior, with listed gaps), `data_only` (named in registries or storage, with no behavior), `missing`, and `not_applicable` (absent from that version, with the reason). **Evidence states:** `compared` (Circuit compared with the official server for named cases), `reference_only` (official observations, Circuit not compared), `documented` (public documentation only), `mismatch` (a comparison shows a difference) and `none`. Counts of different kinds of features are not comparable, so no overall percentage is given.
