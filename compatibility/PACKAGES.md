# Work packages

Generated by `tools/compat_ledger.py` from [`packages.json`](packages.json) and the mechanics in [`families/`](families/); do not edit.

A work package is the unit in which open mechanics of the [ledger](../docs/VANILLA_LEDGER.md) are planned and closed. A mechanic is open in a version while it is `partial`, `data_only` or `missing` there. Every open mechanic names the packages its remaining gaps wait for, and a package cannot be marked closed while an open mechanic names it. A mechanic with gaps in several packages is counted under each of them.

Sizes are relative: S is up to 3 sub-tasks, M 4 to 8, L 9 to 20, XL more or a new subsystem; a package without a size is named only. A hard prerequisite is a package without which this one cannot be implemented; an evidence prerequisite must exist before it can be verified. Enumerated resources (blocks, items and the other inventories) are not assigned to packages.
